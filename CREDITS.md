Everything else is original to this project:

- **Planes** (5 liveries x 3 lengths x 8 colors) and **travelers** (8 characters x 8 colors, plus 4 outfit overlays) are SVG files generated by `scripts/generate-art.ts` (`npm run gen:art`).
- **UI** (buttons, panels, ribbons, icons, coins, stars), **destination scenery** (10 cities and 5 airport themes) and effects are drawn in code (`src/ui/`).
- **Music** and the fallback sounds are synthesized live with WebAudio (`src/systems/MusicEngine.ts`, `src/systems/AudioManager.ts`). The only audio files are the clips in the table above.
- The logo, favicon and app icons (`logos/`, `public/`, Android and iOS icon sets) were made for this project with the MIT-licensed [logo-designer skill](https://github.com/neonwatty/logo-designer-skill) workflow.

Earlier builds used the Kenney UI Audio and Puzzle Pack II files; they are no longer in the game (see git history).
